# latest 镜像标签

## 目标

两个公开镜像提供 latest，用户无需每次修改版本号。用户已授权自动发布官方稳定版；本次明确要求增加滚动标签。

## 要求

- 两镜像各自的版本索引都发布且验证通过后，才开始更新 latest，保持 amd64/arm64。
- 保留完整版本标签和源码追溯；latest 复用已测试的版本索引，不重新构建。
- 旧官方版本或过期源码任务不能覆盖 latest；发布任务串行，检查失败明确停止。
- 英文/中文 README 与配置入口同步支持 latest，说明拉取并重建才更新容器；固定版本用于需要可控升级的用户。

## 验收

失败回归覆盖任一版本索引失败、过期发布、latest 更新失败和内容不符；正常流程两标签都与版本索引一致。真实 GitHub CI 与双架构发布通过，匿名验证两个 latest；不修改生产服务、数据库或 stack。
