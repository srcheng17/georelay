# TeslaMate 高德适配最小版本

## 目标与授权

维护官方稳定 TeslaMate 的最小 URL 补丁，用独立 sidecar 改善地址解析，避免维护完整 fork。用户明确授权：先完成约定和计划，再实施可验证 MVP 并同步现有私有 GitHub；无需真实 Key、不操作生产。

用户后续明确选择：**大陆高德、境外 OSM，减少对高德海外权限的依赖**。客户端自行进行地图显示纠偏；数据库和 adapter 返回坐标保持 WGS84。

## 要求与验收

- R1 固定 v4.3.0 / 33d200b2fba9d5138803916a788cef5eae31b1aa。新增 NOMINATIM_BASE_URL 默认 OSM，HTTP/HTTPS origin 校验，Geocoder 与 Finch pool 共用 URL，保留 proxy/size=3。补丁严格应用，Elixir 格式、编译及测试通过。
- R2 标准库 sidecar 提供 reverse、lookup、health；大陆高德查询临时 WGS84→GCJ02，响应保留原坐标；境外 OSM 不依赖高德权限。不能用矩形冒充大陆边界：框内失败通过 OSM 国家/港澳 ISO 地区确认，只有明确非大陆才接受，大陆保留高德错误。
- R3 SQLite 永久坐标→负 node ID，事务/唯一约束保证并发稳定；重启、TTL、语言不换身份。成功 OSM 结果的对象来源持久化，50 条境外语言刷新可批量 lookup；严格匹配请求身份，同一来源可展开多个本地身份。
- R4 输入、请求体、超时有界，无自动重试；有效缓存优先，失败非200且不生成 Unknown。缺配置、非法/不存在身份明确失败，拒绝来源不明的正数历史 ID。模拟测试覆盖真实本地 HTTP、慢响应、隐私和完整请求预算。
- R5 非 root 私网容器，无 host port、不打印 Key/精确位置；永久映射在线备份可验证，缓存清理不得删除身份。
- R6 稳定 release 检测只产出建议 pin；固定 tag/commit、补丁、测试、镜像构建串联，失败阻止发布。仅 main 手动发布已验证版本镜像，不动 stable、不部署。
- R7 中文 README 说明配置、验证、许可和限制；私有 GitHub 分支/PR 可审查，现场核实真实 checks。

## 不在本任务内

生产部署、历史数据库/正数 hash 迁移、Tesla 凭据、地图底图和客户端显示改造、逐 GPS 点实时解析。真实 Key/额度/海外账户能力未验证。4.0.1→4.3.0 数据迁移和可恢复回滚必须另行授权，不把无 Key 模拟验收等同生产上线。
