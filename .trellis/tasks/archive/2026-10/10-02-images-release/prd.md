# 自动构建与镜像发布

## 目标

用户直接拉取发布的补丁版 TeslaMate 和独立适配器，无需源码构建。官方稳定版更新后自动固定版本、测试、构建并发布版本镜像。

## 要求

- 用户已明确选择检查通过后自动发布新版本镜像，不更新正在运行的服务。
- 支持 linux/amd64 和 linux/arm64，两镜像使用同一版本标签。
- 定时检测官方稳定 release，固定 tag/解引用 commit。自动更新只改 upstream.json，保存可审查分支和 PR，不自动合并更新 PR。
- 补丁冲突、移动 tag、测试或任一架构失败，停止发布；从已测试的镜像产物发布，不重新构建，不自动提升 latest/stable。
- 两个 GHCR package 公开可匿名拉取；中英文使用入口以发布镜像为主，源码构建保留给开发者。
- 初次按正常保护流程合并现有 PR 后发布，不绕过 checks、不 force push。

## 验收

1. 保留 main 保护需要的 verify 汇总检查；任一架构失败，汇总失败且不能发布。
2. 自动更新逻辑可验证 current/new/existing、移动 tag、命令失败与恢复边界；不改补丁或覆盖已有分支。
3. 实际 CI 两架构 Python/ExUnit、严格补丁、镜像架构/许可/非 root 健康检查通过。
4. 两个发布索引恰含 amd64/arm64；实际匿名拉取验证通过，source commit/pin 可公开追溯。
5. 双语配置一致，实际发布标签与文档匹配；链接、渲染和独立审查通过。

## 边界

不部署、迁移、连接生产数据库或取真实 Key；不自动合并上游更新 PR，不复制完整官方源码，不升级无关依赖。
