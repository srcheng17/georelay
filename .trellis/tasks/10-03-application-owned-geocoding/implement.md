# 实施计划

## 进入实施前

- 用户审阅最终规划摘要，并在后续消息明确同意实施；再运行 task.py start。
- 上下文 manifests 必须引用真实 spec/research 文档，task.py validate 通过。
- 在当前隔离工作区为本任务使用独立分支；保留此前 README 删除，不恢复或混入无关内容。

## 交付顺序与子任务

- Release 子任务按其 implement.md 独立实现、检查和审阅；可先交付，架构代码可在隔离分支并行。
- 可信 main writer 的明确用户审阅启用必须先于架构版本正式发布。当前任务若创建 PR，保持 draft 供审阅，既有控制器不能自动合并当前任务；实施批准不含合并/上线授权。
- 最终集成验证父 AC9/AC10：真实版本说明含迁移/配套升级/回滚约束，记录失败不能被视为发布完成；native-token和线上发布证据按实际结果标注。

## 顺序

1. **隔离可行性与迁移前置**：核对固定官方源码、Address schema/精度、插入唯一约束和序列边界。用虚构 fixture 证明高精度历史回填、完整编号范围、候选插入冲突及来源保留；确认自动数据库迁移/导入/启用路径的安全顺序及显式 fresh 初始化；不以 PG 空库推断旧编号未分配。若涉及新的产品取舍或扩大范围，回到规划。
2. **应用所有权**：在地址补丁中实现 PG 管理身份、坐标去重和元数据；保留默认官方路径。网络请求放在长事务外，失败不生成 Unknown。保留历史 ID，不直接用地址主键改号。
3. **新适配器协议与可丢弃缓存**：实现版本化 JSON 请求、批量上下文、按本次身份封装模板缓存、过期缓存清理与新健康检查；恢复所有现有 provider/region/语言/deadline/OSM 批量限流语义。
4. **历史迁移工具**：提供只读预览、脱敏审计和显式 apply 导入；验证缺失/冲突证据停止，旧 SQLite 高水位、序列空洞及部分失败安全。只对隔离恢复副本做写入验证。
5. **最终 release 验证**：同步 fixture/RPC/主镜像检查，真实启动新 PG 迁移与地址契约；加入旧 schema/身份的隔离迁移场景。删除适配器缓存后重启，再验证历史地址刷新。
6. **文档与 specs、版本说明**：同步中英文 README、配置/Compose 示例、迁移与回滚指南、修改通知、接口和发布质量约束；不恢复用户已删除的上游功能/截图/旧镜像改名说明；添加本次可读变更条目，包含破坏性协议升级、历史迁移与回滚条件。
7. **质量检查与收尾**：独立 reviewer 检查跨层流、范围、失败路径和历史身份。通过本地必要检查后整理提交；若 push/PR，报告分支、PR 和实际 checks，等待审阅，未经当前任务明确授权不合并。

## 检查与证据

- python3 -m unittest discover -s tests -v
- git diff --check；所改 shell/Python/workflow 的相关语法和现有 lint。
- 对固定 tag/commit 执行 prepare、git apply --check、上游 Elixir 格式与相关 ExUnit；沿用 scripts/test_upstream.sh 的隔离边界。
- 已构建镜像内运行 adapter suite；主应用默认入口连接全新隔离 PostgreSQL，验证真实迁移、HTTP 登录页面和 compiled 地址契约。
- 扩展覆盖：历史高精度相邻点、负身份不重编号、全 SQLite 高水位/无引用身份、并发收敛、来源切换不丢失、协议错配、50 项查询、删除缓存、TTL、语言、provider/region、上游失败/超时与清理、单地址/整批响应/迁移原子边界、输入精度复用边界及应用 POST 日志脱敏。
- 真实云端 amd64/arm64 checks 仅在另行 push/PR 后按实际结果报告；本地测试不冒充双架构 CI。
- 不读取生产坐标/凭据，不操作生产 PostgreSQL 或容器；测试数据使用虚构公共坐标和独立卷/网络，失败清理有界。

## 回滚点与禁止事项

历史迁移工具先预览；变更前保留受控副本。模型/协议切换后需匹配的 PG/旧 SQLite 截止点恢复，不能仅回退旧镜像；不加入长期双写。出现坐标/身份/来源冲突、溢出或未完成导入时停止新路径，不猜测修复。不得改 main、启用新的 auto-merge 或用旧任务授权合并。

## Release 集成检查

- 子任务上下文、状态与父子链接一致；PRD/design/implement覆盖发布结果、补录、首次启用和权限门禁。
- 父任务正式发行的说明来自exact source，本地迁移说明、两镜像配套版本与Release内容一致。
- 仓库工作流既有自动化合并边界不扩张；当前任务的用户审阅门禁仍生效。
