# 多供应商逆地理解析

## 目标

地址解析支持高德、百度与 OSM。用户已选择环境变量默认策略和请求参数覆盖，并授权提供的开发凭据进行隔离联调。

## 要求

- 默认延续大陆高德、境外 OSM；可将大陆服务改为百度，或固定使用任一服务。
- /reverse、/lookup 的 provider=amap|baidu|osm 覆盖默认策略；TeslaMate 不需要额外补丁。
- 切换服务、语言、TTL 或重启不改变永久负 ID 和原 WGS84 坐标。
- 不同策略的缓存互不误用；从已有 SQLite 迁移保留身份映射。
- 百度使用匹配的 AK/SK 进行 SN 验证，直接请求 WGS84；高德仅临时转换查询坐标。
- 上游权限或网络失败明确返回非 200，不生成永久 Unknown。
- 官方技能安装保持来源，评估服务端价值；英文 README 与中文配置同步。

## 验收

模拟检查涵盖参数验证、三服务映射、官方 SN 示例、实际请求编码、迁移、provider 切换、OSM 来源与地域判定隔离、TTL/重启/lookup；隔离真实公共地标联调核对 SN 和原坐标/身份闭环。最终现有 PR 的双架构 CI 通过并按已授权流程发布。

## 边界

不改前端底图、不执行生产部署或历史迁移。凭据、完整响应和数据库不入 Git。
