# 前端边界

本仓库没有独立前端。地址 sidecar 不改变客户端地图瓦片。GeoRelay 修改版通过受测上游模板补丁和四条已知 gettext 消息的受控转换替换公开应用名称、Logo 和图标，并展示来源及免责声明；此品牌范围不改页面功能、地图 provider 或第三方代理。底图工作需要独立任务和来源/许可核查。后端变更参见 `../backend/index.md`。

公开品牌以实际渲染结果验证；内部模块/脚本等技术标识和必要法律署名允许保留 TeslaMate。无关静态目录变化不应触发全量品牌审核，未知新增视觉资源仍需复核。准备与测试边界见 `../backend/quality-guidelines.md` 的上游品牌准备契约。
