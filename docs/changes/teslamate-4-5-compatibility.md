# TeslaMate v4.5.0 兼容性

适配 TeslaMate v4.5.0 的地址接口、补丁和镜像测试。使用上游串行化的语言切换流程，先查询并验证全部地址，再将地址字段与语言设置一起提交。公共 Nominatim 查询继续遵循上游限流，应用身份模式保留既有 PostgreSQL 身份和适配器协议。

应用身份模式要求显式配置适配器地址，独立于公共 Nominatim 的代理。高德和百度结果在相同路由与来源条件下可跨语言复用。已失效的 OSM 来源可以先预览、再确认修复，保留地址主键、精确坐标及历史引用。

自动升级在派发双架构构建前检查补丁兼容性。镜像发布索引仅引用通过架构校验的可运行清单。
