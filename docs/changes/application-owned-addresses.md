# 应用统一管理地址身份

永久地址身份、精确 WGS84 原坐标和经验证的供应商来源改由 TeslaMate/PostgreSQL 管理。适配器通过版本化请求接收这些数据，仅保存可删除的文字缓存；缓存到期、清理或重建不会改变历史地址。

应用和适配器必须使用同一配套版本，并设置 GEORELAY_ADDRESS_MODE=application。新安装要显式初始化；使用旧 SQLite 身份库的安装须先审计导入，保留原编号、数据库主键、行程和充电关联。导入恢复可证明的原始地址精度，不修改 positions 轨迹，不按邻近坐标合并。

旧身份数据库仅作迁移/回滚档案。新模式分配新编号后，只降级镜像不能安全恢复旧模式；需要匹配截止点的 PostgreSQL 与旧 SQLite 备份。详细步骤见 docs/AMAP.md 的“永久身份与备份”。
